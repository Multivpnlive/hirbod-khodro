# هیربد خودرو | Hirbod Khodro

**نسخه انتشار: 1.1.0**

سامانه فارسی مدیریت خریدوفروش خودرو، حسابداری شرکا و مدیریت مالی کسب‌وکارهای خودرویی؛ قابل نصب روی سرور اختصاصی با Ubuntu.

---

## امکانات اصلی

- مدیریت خودروها، مشتریان و معاملات
- مدیریت حساب‌های مالی و سهم شرکا
- مدیریت دریافتنی‌ها، حواله‌ها و کارمزدها
- تعریف و مدیریت دسترسی کارکنان
- ثبت سوابق مالی و حفظ تاریخچه شرکا
- پشتیبان‌گیری و بازیابی اطلاعات با فایل `.hirbod`
- رابط کاربری فارسی با پوسته‌های روشن و تیره
- نصب و به‌روزرسانی نسخه‌بندی‌شده

## پیش‌نیازهای نصب

- سرور VPS با Ubuntu 22.04 یا جدیدتر
- معماری پردازنده x86_64
- دامنه متصل به IP عمومی سرور
- دسترسی مدیریتی root یا sudo
- اتصال اینترنت برای دریافت بسته‌ها و تصاویر Docker

## نصب روی سرور جدید

> این روش برای نصب تازه است؛ برای سروری که قبلاً هیربد خودرو روی آن نصب شده، از بخش «به‌روزرسانی» استفاده کنید.

ابتدا دامنه را به IP سرور متصل کنید. سپس دستور زیر را با جایگزین‌کردن `YOUR_DOMAIN` با دامنه واقعی اجرا کنید:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Multivpnlive/hirbod-khodro/v1.1.0/installer/install-from-github.sh) --domain YOUR_DOMAIN
```

نصب‌کننده پیش‌نیازها را بررسی و سرویس‌های موردنیاز را راه‌اندازی می‌کند.

## به‌روزرسانی نسخه موجود

برای به‌روزرسانی، ابتدا وارد پوشه مخزن برنامه روی سرور شوید؛ همان پوشه‌ای که دایرکتوری `installer` در آن قرار دارد.

### ۱. پیش‌بررسی به‌روزرسانی (بدون اعمال تغییرات)

این مرحله وضعیت نسخه، سلامت سرویس و شرایط لازم برای به‌روزرسانی را بررسی می‌کند؛ اما به‌روزرسانی را اعمال نمی‌کند.

```bash
bash installer/update-from-github.sh --health-url https://YOUR_DOMAIN --dry-run
```

### ۲. اعمال به‌روزرسانی

پس از بررسی نتیجه مرحله قبل و اطمینان از داشتن نسخه پشتیبان معتبر، برای اعمال به‌روزرسانی اجرا کنید:

```bash
bash installer/update-from-github.sh --health-url https://YOUR_DOMAIN --yes
```

> گزینه `--yes` به‌روزرسانی واقعی را اجرا می‌کند. بدون بررسی نتیجه پیش‌بررسی و تهیه پشتیبان، آن را اجرا نکنید.

## پشتیبان‌گیری و بازیابی

پشتیبان‌گیری زمان‌بندی‌شده در نصب استاندارد فعال می‌شود. فایل‌های پشتیبان با پسوند `.hirbod` برای نگهداری و بازیابی اطلاعات استفاده می‌شوند.

- فایل‌های پشتیبان را در محل امن و مستقل از سرور نگهداری کنید.
- پیش از عملیات مهم، از معتبر و قابل‌بازیابی بودن نسخه پشتیبان اطمینان حاصل کنید.
- دسترسی به فایل‌های پشتیبان را محدود نگه دارید.

## نکات مهم درباره پایگاه داده

اسکریپت به‌روزرسانی برنامه، مهاجرت‌های پایگاه داده (Database Migrations) را به‌صورت خودکار اجرا نمی‌کند.

در صورت نیاز به مهاجرت، ابتدا نسخه پشتیبان تهیه کنید و مراحل مربوط به همان انتشار را طبق مستندات و دستورالعمل انتشار اجرا کنید. از اجرای دستی یا تکراری مهاجرت‌ها خودداری کنید.

## امنیت و نگهداری

- فایل‌های دارای اطلاعات محرمانه و متغیرهای محیطی را در مخزن Git قرار ندهید.
- از `.env.example` فقط به‌عنوان الگوی تنظیمات استفاده کنید.
- کلیدها و گذرواژه‌های اختصاصی هر سرور باید روی همان سرور نگهداری شوند.
- قبل از به‌روزرسانی، سلامت سرویس و وضعیت پشتیبان‌گیری را بررسی کنید.
