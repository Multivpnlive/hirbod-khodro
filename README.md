# هیربد خودرو | Hirbod Khodro

**نسخه انتشار: 1.1.8**

سامانه فارسی مدیریت خریدوفروش خودرو، حسابداری شرکا و مدیریت مالی کسب‌وکارهای خودرویی؛ قابل نصب روی سرور اختصاصی با Ubuntu.

---

## امکانات اصلی

- مدیریت خودروها، مشتریان و معاملات
- مدیریت حساب‌های مالی و سهم شرکا
- مدیریت دریافتنی‌ها، حواله‌ها و کارمزدها
- تعریف و مدیریت دسترسی کارکنان
- ثبت سوابق مالی و حفظ تاریخچه شرکا
- پشتیبان‌گیری و بازیابی اطلاعات با فایل `.hirbod`
- رابط کاربری فارسی با پوسته‌های روشن و تیره
- نصب و به‌روزرسانی نسخه‌بندی‌شده

## پیش‌نیازهای نصب

- سرور VPS با Ubuntu 22.04 یا جدیدتر
- معماری پردازنده x86_64
- دامنه متصل به IP عمومی سرور
- دسترسی مدیریتی root یا sudo
- اتصال اینترنت برای دریافت بسته‌ها و تصاویر Docker

## نصب روی سرور جدید

ابتدا دامنه را به IP سرور متصل کنید. سپس فقط این دستور را روی سرور اجرا کنید:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Multivpnlive/hirbod-khodro/main/installer/install-from-github.sh)
```

نصب‌کننده آخرین نسخه را دریافت می‌کند، دامنه را می‌پرسد و نصب را کامل انجام می‌دهد. نیازی به ورود به پوشه پروژه نیست.

## به‌روزرسانی

فقط این دستور را اجرا کنید:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Multivpnlive/hirbod-khodro/main/installer/update-from-github.sh)
```

دامنه از تنظیمات Caddy تشخیص داده می‌شود. حالت پیش‌فرض پیش‌بررسی بدون تغییر است. برای بروزرسانی واقعی، گزینه ۲ را انتخاب و عبارت UPDATE را وارد کنید.

در بروزرسانی واقعی، پیش از اعمال مهاجرت‌های جدید دیتابیس، اسکریپت به‌صورت خودکار نسخهٔ پشتیبان می‌گیرد و صحت آن را بررسی می‌کند. اگر مهاجرت یا تهیهٔ پشتیبان موفق نشود، برنامهٔ جدید جایگزین نمی‌شود.

### اجرای دستوری اختیاری

```bash
bash installer/update-from-github.sh --domain app.example.com --dry-run
bash installer/update-from-github.sh --domain app.example.com --yes
```

## نصب وب‌اپ روی دسکتاپ و موبایل

برنامه روی دامنهٔ دلخواه هر نصب و از طریق HTTPS قابل نصب است. پس از باز کردن نشانی برنامه:

- **رایانه (Chrome یا Edge):** دکمهٔ نصب کنار نوار بالای برنامه یا نماد نصب در نوار نشانی مرورگر را انتخاب کنید.
- **Android (Chrome):** منوی مرورگر را باز کنید و «Install app» یا «Add to Home screen» را بزنید.
- **iPhone و iPad (Safari):** دکمهٔ Share را بزنید، سپس «Add to Home Screen» را انتخاب کنید.

نام و آیکون وب‌اپ با برند تنظیم‌شده برای همان نصب هماهنگ می‌شوند. اگر برند یا لوگو بعد از نصب عوض شد، میانبر قدیمی را حذف و وب‌اپ را دوباره نصب کنید.

## ایمیل تأیید حساب و بازیابی رمز عبور

راهنمای کامل راه‌اندازی از ساخت حساب Resend و تأیید دامنهٔ فرستندهٔ دلخواه هر نصب تا نصب روی سرور و آزمایش بازیابی رمز عبور:

**[باز کردن راهنمای صفر تا صد ایمیل](installer/README.md)**

برای هر سرور، دامنهٔ فرستندهٔ همان نصب را در [Resend](https://resend.com/signup) تأیید کنید، یک API Key با دسترسی Sending بسازید و سپس روی همان سرور اجرا کنید:

```bash
cd /opt/hirbod/app
bash installer/setup-email.sh
```

برای بررسی سلامت بدون تغییر تنظیمات:

```bash
bash installer/setup-email.sh --check
```

آموزش کامل محل ورود به DNS، واردکردن رکوردهای مخصوص دامنه، ساخت کلید، نصب، آزمایش و رفع اشکال در [راهنمای صفر تا صد](installer/README.md) است. اسکریپت مستقل: [installer/setup-email.sh](installer/setup-email.sh).

کلید Resend فقط روی همان سرور نگهداری می‌شود. فایل‌های بکاپ نسخهٔ ۳ این تنظیمات را بدون رمزگذاری دارند؛ دسترسی به فایل‌های بکاپ را محدود نگه دارید.

## پشتیبان‌گیری و بازیابی

پشتیبان‌گیری زمان‌بندی‌شده در نصب استاندارد فعال می‌شود. فایل‌های پشتیبان با پسوند `.hirbod` برای نگهداری و بازیابی اطلاعات استفاده می‌شوند.

- فایل‌های پشتیبان را در محل امن و مستقل از سرور نگهداری کنید.
- پیش از عملیات مهم، از معتبر و قابل‌بازیابی بودن نسخه پشتیبان اطمینان حاصل کنید.
- دسترسی به فایل‌های پشتیبان را محدود نگه دارید.

## نکات مهم درباره پایگاه داده

اسکریپت به‌روزرسانی برنامه، مهاجرت‌های پایگاه داده (Database Migrations) را به‌صورت خودکار اجرا نمی‌کند.

در صورت نیاز به مهاجرت، ابتدا نسخه پشتیبان تهیه کنید و مراحل مربوط به همان انتشار را طبق مستندات و دستورالعمل انتشار اجرا کنید. از اجرای دستی یا تکراری مهاجرت‌ها خودداری کنید.

## امنیت و نگهداری

- فایل‌های دارای اطلاعات محرمانه و متغیرهای محیطی را در مخزن Git قرار ندهید.
- از `.env.example` فقط به‌عنوان الگوی تنظیمات استفاده کنید.
- کلیدها و گذرواژه‌های اختصاصی هر سرور باید روی همان سرور نگهداری شوند.
- قبل از به‌روزرسانی، سلامت سرویس و وضعیت پشتیبان‌گیری را بررسی کنید.
